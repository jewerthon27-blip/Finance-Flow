# 💰 Finance Flow Pro

Uma interface de gerenciamento financeiro moderna, limpa e intuitiva para controle de gastos pessoais.

## 🎯 Objetivo
O projeto foi desenvolvido para facilitar a visualização da saúde financeira, permitindo o registro rápido de transações e a análise visual através de gráficos dinâmicos.

## 🚀 Funcionalidades Principais
* **Cálculo Automático**: Monitoramento em tempo real de Saldo Disponível, Receitas e Despesas.
* **Análise Visual**: Gráfico de rosca dinâmico para categorização de gastos.
* **Histórico Detalhado**: Lista de atividades para conferência de transações passadas.
* **Interface Responsiva**: Design em tons de azul ("Flow") otimizado para clareza visual.

## 🛠️ Tecnologias Utilizadas
* **HTML5**: Estrutura semântica da página.
* **CSS3**: Estilização personalizada com foco em experiência do usuário.
* **JavaScript**: Lógica de cálculos e manipulação de dados.
* **Chart.js**: Biblioteca utilizada para a renderização dos gráficos.
